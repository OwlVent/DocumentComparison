<h1>DocumentComparison</h1>

A service for comparing two documents. Currently, you can compare two documents in CSV format.

## How to run:
<ol>
  <li>Download the latest jar file from <a href="https://github.com/OwlVent/DocumentComparison/releases">the releases</a></li>
  <li>In the console, enter the following code <pre><code>java -jar [name-file].jar</code></pre></li>
  <li>In any browser, enter <a href="http://localhost:8080/">http://localhost:8080/</a></li>
  <li>Select the required format for the files being compared and upload them</li>
</ol>
